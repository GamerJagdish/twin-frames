Twin Frames is a spot the difference game for the desktop browser: two hand-drawn canvas scenes side by side (a harbour at dusk, an alpine meadow, a night market), with objects removed, added, recoloured, resized, mirrored or nudged in the copy. Six levels raise the count and subtlety of the changes against a draining clock, with misses costing time, streak bonuses for quick finds and three hints per run. It plays with the mouse, or with the arrow keys and Enter.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
